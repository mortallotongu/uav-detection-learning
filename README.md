# UAV Detection Learning · Foundation v2

当前只实现 Phase A1：最小数学直觉、图像/张量、神经网络训练和 CNN 机制。A2 Feature Pyramid/Detection、A3 Transformer、A4 DETR 均保持锁定。

## 开始

电脑可直接双击 `index.html`。手机 PWA 仍需通过 HTTPS 或 localhost 访问；部署方式见 `DEPLOYMENT.md`。

推荐顺序：A1.1 → A1.2 → A1.3 → A1.4。总学习时间约 10–13 小时，分多天完成。第一天只执行 `00_Start_Here/Day1.md`。

每个困难概念是独立单元，包含前置链接、30 秒解释、5 分钟解释、Deep Dive、Why、书签与主动回忆。术语表见 `glossary.html`，常见误区见 `misconceptions.html`。

修改前 v1 保存在 `backups/phase-a-v1-20260817.tar.gz`；教学审计见 `AUDIT_FOUNDATION_V1.md`。

进度与书签只保存在当前浏览器，不跨设备同步。本项目不包含 API keys、密码、私人研究凭据或未公开研究代码。
